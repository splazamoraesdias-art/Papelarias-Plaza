# 🖋️ Papelaria Plaza - Personalizados de Luxo

Bem-vindo ao repositório oficial da **Papelaria Plaza**! Este é o site institucional e catálogo digital da nossa papelaria, focada em transformar itens do dia a dia em memórias únicas através da personalização.

## 🌟 Sobre a Papelaria Plaza
A Papelaria Plaza nasceu da paixão pelo papel e pelo design. Especializamo-nos em produtos sob medida para quem busca organização com estilo e exclusividade. 

Nossos principais produtos incluem:
* **Agendas e Planners:** Organização personalizada com o seu nome.
* **Cadernos Kraft:** Estilo rústico e elegante para ideias criativas.
* **Kits de Luxo:** Conjuntos ideais para presentes corporativos ou pessoais.

## 🚀 Tecnologias Utilizadas
Este projeto foi desenvolvido utilizando as melhores práticas de desenvolvimento web moderno:
* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Design responsivo (Mobile First) e estilização personalizada.
* **Google Fonts:** Tipografia selecionada para melhor legibilidade.
